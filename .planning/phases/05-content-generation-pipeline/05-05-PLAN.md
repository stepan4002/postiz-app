<objective>
Build the Review Queue UI where operators review, approve, reject, regenerate, and edit AI-generated content before it moves to the scheduling pipeline.

Purpose: The review queue is the operator's daily workspace. Low-confidence posts are routed here automatically by confidence gating. The UI must be efficient for reviewing multiple posts quickly with inline editing capability.

Output: ReviewQueueList page component, ReviewQueueItem cards with action buttons, confidence badges, inline caption editor, and SWR hooks for data fetching and mutations.
</objective>
