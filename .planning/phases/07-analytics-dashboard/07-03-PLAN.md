<objective>
Build the pre-computed dashboard pipeline: DashboardRepository, DashboardService, DashboardSummaryJob (@Cron every 15 minutes), and DashboardController.

Purpose: Provide the operator's daily command centre with pre-computed data that loads in under 2 seconds. The DashboardSummaryJob runs every 15 minutes and computes per-company counts (scheduled today, pending review, failed posts) plus top performing posts, storing results in DashboardCache. The controller reads only from this cache — never queries live data or platform APIs.

Output: Complete dashboard data pipeline with pre-compute cron and REST endpoint for frontend consumption.
</objective>

    2. Create dashboard-summary.job.ts:
       - Class DashboardSummaryJob
       - private readonly logger = new Logger(DashboardSummaryJob.name)
       - Constructor: dashboardRepo (DashboardRepository), prisma (any)
       - @Cron('*/15 * * * *') refreshDashboardCache():
         - FIRST LINE: if (!process.env.RUN_CRON) return; — RUN_CRON guard (critical)
         - Fetch all companies: prisma.company.findMany({ select: { id: true } })
         - For each company: await this.refreshForCompany(company.id) inside try/catch (per-company error isolation)
         - Log summary: `Dashboard cache refreshed for ${successCount}/${companies.length} companies`

       - private async refreshForCompany(companyId: string): Promise&lt;void&gt;:
         - Compute "today" as start of day UTC (new Date() with hours/minutes/seconds zeroed)
         - Compute tomorrow as today + 24h
         - Compute sevenDaysAgo as today - 7 days
         - Use Promise.all for 7 parallel queries:

           a. scheduledTodayCount: prisma.postVariant.count({
                where: { post: { companyId }, status: { in: ['SCHEDULED', 'PUBLISHING'] }, scheduledAt: { gte: today, lt: tomorrow } }
              })

           b. pendingReviewCount: prisma.postVariant.count({
                where: { post: { companyId }, status: 'PENDING_REVIEW' }
              })

           c. failedPostsCount: prisma.postVariant.count({
                where: { post: { companyId }, status: { in: ['FAILED', 'STALE'] } }
              })

           d. topPosts: prisma.postMetrics.findMany({
                where: { companyId, fetchedAt: { gte: sevenDaysAgo } },
                orderBy: [{ likes: 'desc' }, { comments: 'desc' }, { shares: 'desc' }],
                take: 5,
                include: { variant: { select: { id: true, caption: true, platform: true, publishedAt: true, postId: true } } }
              })
              Then map to TopPerformerEntry[]: compute totalEngagement = (likes || 0) + (comments || 0) + (shares || 0)

           e. scheduledPosts: prisma.postVariant.findMany({
                where: { post: { companyId }, status: { in: ['SCHEDULED', 'PUBLISHING'] }, scheduledAt: { gte: today, lt: tomorrow } },
                take: 20, orderBy: { scheduledAt: 'asc' },
                include: { post: { select: { brandId: true }, include: { brand: { select: { name: true } } } } }
              })
              Map to ScheduledPostSummary[]

           f. failedPosts: prisma.postVariant.findMany({
                where: { post: { companyId }, status: { in: ['FAILED', 'STALE'] } },
                take: 20, orderBy: { publishedAt: 'desc' },
                select: { id: true, postId: true, platform: true, caption: true, status: true, lastPublishError: true, consecutiveFailures: true }
              })
              Map to FailedPostSummary[]

           g. pendingReview: prisma.postVariant.findMany({
                where: { post: { companyId }, status: 'PENDING_REVIEW' },
                take: 20, orderBy: { generatedAt: 'desc' },
                select: { id: true, postId: true, platform: true, caption: true, confidenceScore: true, generatedAt: true }
              })
              Map to PendingReviewSummary[] (generatedAt -> createdAt in summary)

         - await this.dashboardRepo.upsertCache(companyId, {
             scheduledTodayCount, pendingReviewCount, failedPostsCount,
             topPostsJson: topPosts, scheduledPostsJson: scheduledPosts,
             failedPostsJson: failedPosts, pendingReviewJson: pendingReview,
             computedAt: new Date()
           })
