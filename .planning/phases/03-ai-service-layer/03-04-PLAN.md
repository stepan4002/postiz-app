    1. Create `extensions/ai-service/src/router/ai-provider.router.ts`:
       - @Injectable() class AIProviderRouter
       - Constructor injects: OpenAIProvider, AnthropicProvider, OllamaProvider, AIConfigService, AICostLogger, BudgetCircuitBreaker, BrandVoicePromptBuilder, PrismaService (for BrandVoice lookup)
       - Private `providers: Map<string, IAIProvider>` initialized in constructor:
         ```
         this.providers = new Map([
           ['openai', openaiProvider],
           ['anthropic', anthropicProvider],
           ['ollama', ollamaProvider],
         ]);
         ```
       - Private `DEFAULT_MODELS: Record<string, string>`:
         ```
         { openai: 'gpt-4o-mini', anthropic: 'claude-haiku-4-5', ollama: 'llama3' }
         ```
       - Private `VISION_MODELS: Record<string, string>`:
         ```
         { openai: 'gpt-4o', anthropic: 'claude-sonnet-4-5' }
         ```

       - `async execute<T>(context: AICallContext, messages: AIMessage[], schema: z.ZodType<T>): Promise<AICallResult<T>>`:
         1. `await this.budgetCircuitBreaker.checkBudget(context.companyId)` — throws BudgetExceededError if over budget
         2. `const config = await this.aiConfigService.findByCompany(context.companyId)`
         3. Select provider: `this.selectProvider(config.defaultProvider, context.taskType)`
         4. Select model: `config.preferredModels[context.taskType] ?? this.DEFAULT_MODELS[provider.providerName]`
         5. If context.brandId, look up BrandVoice: `(this.prisma as any).brandVoice.findUnique({ where: { brandId: context.brandId } })`
         6. Build system prompt: if messages have a system message, replace its content with `this.brandVoicePromptBuilder.buildSystemPrompt(brandVoice, originalSystemContent)`. If no system message exists and brandVoice is found, prepend a system message with the brand voice prompt.
         7. `const result = await provider.chat(messages, schema, model)`
         8. `await this.costLogger.log({ companyId: context.companyId, postId: context.postId, provider: provider.providerName, model: result.model, taskType: context.taskType, inputTokens: result.usage.inputTokens, outputTokens: result.usage.outputTokens, estimatedCostUsd: result.usage.estimatedCostUsd })`
         9. Return result

       - `async executeImageAnalysis<T>(context: AICallContext, imageUrl: string, prompt: string, schema: z.ZodType<T>): Promise<AICallResult<T>>`:
         1. Check budget
         2. Get config
         3. Select provider (prefer providers that support 'analyzeImage')
         4. Use VISION_MODELS[provider.providerName] for model selection
         5. If brandId, build brand voice system prompt and prepend to prompt
         6. Call provider.analyzeImage(imageUrl, prompt, schema, model)
         7. Log cost
         8. Return result

       - Private `selectProvider(preferredProvider: string, taskType: AITaskType): IAIProvider`:
         - Get preferred from this.providers.get(preferredProvider)
         - If preferred exists and supports taskType -> return it
         - Else: iterate providers, return first that supports taskType
         - If none found: throw new Error(`No provider available for task type: ${taskType}`)
