  <behavior>
    - checkBudget(companyId) does nothing if no weeklyBudgetUsd configured (null = unlimited)
    - checkBudget(companyId) queries AICostLog aggregate sum of estimatedCostUsd where createdAt >= startOf('week')
    - checkBudget(companyId) throws BudgetExceededError if spent >= weeklyBudgetUsd
    - checkBudget(companyId) passes silently if spent < weeklyBudgetUsd
    - BudgetExceededError includes spent amount and budget limit in message
    - Weekly window uses dayjs().startOf('week') in UTC
  </behavior>
  <action>
    1. Create `extensions/ai-service/src/cost/budget-circuit-breaker.service.ts`:
       - Export class BudgetExceededError extends Error (with companyId, spent, budget as properties)
       - @Injectable() class BudgetCircuitBreaker
       - Constructor: inject PrismaService and AIConfigService
       - `async checkBudget(companyId: string): Promise<void>`:
         - const config = await this.aiConfigService.findByCompany(companyId)
         - if (!config.weeklyBudgetUsd) return; // no budget = unlimited
         - const weekStart = dayjs().utc().startOf('week').toDate()
         - const spent = await (this.prisma as any).aICostLog.aggregate({ where: { companyId, createdAt: { gte: weekStart } }, _sum: { estimatedCostUsd: true } })
         - const spentAmount = spent._sum.estimatedCostUsd ?? 0
         - if (spentAmount >= config.weeklyBudgetUsd): throw new BudgetExceededError(companyId, spentAmount, config.weeklyBudgetUsd)
       - Import dayjs from 'dayjs' and utc plugin: `import utc from 'dayjs/plugin/utc'; dayjs.extend(utc);`

       - Test: spent > budget -> throws BudgetExceededError
       - Test: BudgetExceededError contains companyId, spent, and budget values
