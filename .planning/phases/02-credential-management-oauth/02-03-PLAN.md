    Create src/credential/credential.service.ts:

    @Injectable() CredentialService with constructor injecting:
    - TokenEncryptionService (from Plan 01)
    - PrismaService (from @gitroom/nestjs-libraries)

    Methods:

    1. saveCredential(params: SaveCredentialParams): Encrypts token and refreshToken using TokenEncryptionService.encrypt() before writing. Sets tokenEncrypted=true on the integration record. Calls prisma.integration.update() with encrypted values. Handles the case where refreshToken is null (don't encrypt null).

    2. decryptToken(integration: { token: string, tokenEncrypted: boolean }): string
       - If tokenEncrypted === false, return integration.token as-is (backward compat for pre-encryption tokens)
       - If tokenEncrypted === true, return this.encryption.decrypt(integration.token)

    3. decryptRefreshToken(integration: { refreshToken: string | null, tokenEncrypted: boolean }): string | null
       - Same logic as decryptToken but handles null refreshToken

    4. encryptExistingToken(integrationId: string): Reads integration, encrypts token+refreshToken, saves with tokenEncrypted=true. For one-time migration use.

    Define SaveCredentialParams interface:
    ```typescript
    interface SaveCredentialParams {
      integrationId: string;
      token: string;
      refreshToken: string | null;
      expiresIn?: number;
    }
    ```

    Key design: This service does NOT replace IntegrationService. It wraps the token-specific operations. The upstream IntegrationService.createOrUpdateIntegration() still handles the initial OAuth save -- the OAuthBrandController in Task 2 will call that upstream method and then encrypt via CredentialService.saveCredential().
