    - PlatformMediaValidator.validate: returns passed=true when dimensions, fileSize, format match spec
    - PlatformMediaValidator.validate: returns passed=false with specific reason when dimensions wrong

1. Create `platform-media-validator.ts`:
   - Injectable service (no DB dependency -- pure validation logic)
   - `validate(variant: { width, height, fileSize, format }, platform: string, aspectRatio?: string)`: checks variant against PLATFORM_MEDIA_SPECS. For Instagram, aspectRatio selects which sub-spec (square/portrait/landscape). Returns PlatformValidationResult.
   - `validateAll(variants: Array<{ platform, width, height, fileSize, format }>, platforms: string[])`: returns PlatformValidationResult[] for each platform

   - Inject PrismaService (for MediaVariant creation), MinioStorage (for download/upload)
   - `generateVariant(sourceBuffer: Buffer, spec: VariantSpec)`: sharp(buffer).resize(width, height, { fit: 'cover', position: 'centre' }).jpeg({ quality: 85 }).toBuffer(). Returns VariantResult.
   - `generateVariants(mediaId: string, platforms: string[])`:
     a. Load Media record from DB (get path, companyId)
     b. Download original file from MinIO (GetObjectCommand)
     c. For each platform, look up PLATFORM_VARIANT_SPECS[platform]
     d. For each spec, call generateVariant
     e. Upload variant buffer to MinIO: key = `{companyId}/{mediaId}/variants/{platform}_{w}x{h}.jpg`
     f. Create MediaVariant DB record for each with: mediaId, platform, width, height, path, fileSize
   - Error handling: if sharp fails on corrupt file, throw with descriptive message; caller (job) handles logging

  <action>
1. Create `media-processing.job.ts`:
   - `@Injectable()` class with `@Cron('*/30 * * * * *')` decorated method (every 30 seconds)
   - Inject MediaProcessingService, PrismaService
   - `processPendingJobs()`:
     a. `if (!process.env.RUN_CRON) return;` -- guard per Phase 2 pattern
     b. Find up to 5 pending jobs: `prisma.mediaProcessingJob.findMany({ where: { status: 'pending' }, take: 5, orderBy: { createdAt: 'asc' } })`
     c. For each job:
        - Update status to 'processing': `prisma.mediaProcessingJob.update({ where: { id }, data: { status: 'processing' } })`
        - Call `mediaProcessingService.generateVariants(job.mediaId, job.platforms)`
        - Update status to 'completed': `prisma.mediaProcessingJob.update({ where: { id }, data: { status: 'completed' } })`
        - On error: catch, log with Logger, update status to 'failed' with error message
   - Uses NestJS Logger for all logging (Logger name: 'MediaProcessingJob')
