Output: Complete analytics ingestion pipeline running as a decoupled @Cron background job, plus REST endpoints for per-post analytics.

       - Class AnalyticsRepository, constructor takes prisma (typed as any — consistent pattern)
       - upsertMetrics(variantId, snapshotType, metrics, postId, companyId, platform): Promise&lt;void&gt;
         - Uses prisma.postMetrics.upsert with where: { variantId_snapshotType: { variantId, snapshotType } }
         - create: all fields including fetchedAt: new Date()
         - update: metrics fields + fetchedAt: new Date()
       - findDueForIngestion(batchSize: number): Promise&lt;DueIngestionItem[]&gt;
         - Fetch PUBLISHED variants where publishedAt is at least 1 hour ago AND platformPostId is not null
         - Include metrics (select snapshotType only) to know which snapshots already exist
         - Include post (select companyId, brandId) for company scoping
         - Over-fetch (take: batchSize * 3), then JS-filter to determine which snapshotType is due:
           - elapsed >= 1h AND no '1h' snapshot -> due for '1h'
           - elapsed >= 24h AND no '24h' snapshot -> due for '24h'
           - elapsed >= 7d AND no '7d' snapshot -> due for '7d'
         - Slice to batchSize after filtering
         - Need to join SocialAccount -> Integration to get encrypted accessToken:
           - Query SocialAccount where brandId=post.brandId AND platform=variant.platform
           - Then Integration where id=socialAccount.integrationId to get token field
         - Return DueIngestionItem[] with accessToken (still encrypted — IngestionJob decrypts)
       - findByVariantId(variantId: string): Promise&lt;PostMetrics[]&gt; — all snapshots for a variant, ordered by snapshotType
       - findByPostId(postId: string): Promise&lt;PostMetrics[]&gt; — all metrics for all variants of a post, grouped by variant

    2. Create analytics.service.ts:
       - Class AnalyticsService
       - Constructor: analyticsRepo, tokenEncryption (TokenEncryptionService), adapterRegistry (AnalyticsAdapterRegistry)
       - processVariant(item: DueIngestionItem): Promise&lt;void&gt;
         - Decrypt token: this.tokenEncryption.decrypt(item.accessToken)
         - Get adapter: this.adapterRegistry.getAdapter(item.platform)
         - Fetch metrics: await adapter.fetchPostMetrics(item.platformPostId, decryptedToken, item.platformAccountId)
         - Upsert: await this.analyticsRepo.upsertMetrics(item.variantId, item.snapshotType, metrics, item.postId, item.companyId, item.platform)
         - Logger: log success at debug level
       - getVariantAnalytics(variantId: string): return this.analyticsRepo.findByVariantId(variantId)
       - getPostAnalytics(postId: string): return this.analyticsRepo.findByPostId(postId)

    3. Create analytics-ingestion.job.ts:
       - Class AnalyticsIngestionJob
       - private readonly logger = new Logger(AnalyticsIngestionJob.name)
       - private static readonly BATCH_SIZE = 20
       - Constructor: analyticsService (AnalyticsService), analyticsRepo (AnalyticsRepository)
       - @Cron('*/5 * * * *') ingestPendingMetrics():
         - FIRST LINE: if (!process.env.RUN_CRON) return; — RUN_CRON guard (critical)
         - const due = await this.analyticsRepo.findDueForIngestion(BATCH_SIZE)
         - for (const item of due) { try { await this.analyticsService.processVariant(item) } catch (err) { this.logger.error(...) } }
         - Per-item error isolation: catch inside loop, never rethrow
         - Log batch summary: this.logger.log(`Ingested metrics for ${successCount}/${due.length} variants`)
       - Import Cron from @nestjs/schedule, Logger from @nestjs/common, Injectable from @nestjs/common
