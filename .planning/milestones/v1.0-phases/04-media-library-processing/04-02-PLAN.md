2. Create `company-media.repository.ts`:
   - Inject PrismaService
   - `createMedia(data: { name, path, thumbnail, organizationId, companyId, fileSize, type, width, height, format, tags })`: prisma.media.create
   - `findByCompany(companyId, page, limit, tag?)`: prisma.media.findMany with WHERE companyId + deletedAt IS NULL + optional `tags: { has: tag }`, ORDER BY createdAt DESC, skip/take pagination. Return { items, total, page, totalPages }
   - `findById(id)`: prisma.media.findUnique with include variants
   - `deleteMedia(id)`: prisma.media.update set deletedAt = new Date()
   - `createProcessingJob(mediaId, platforms)`: prisma.mediaProcessingJob.create with status 'pending'

3. Create `company-media.service.ts`:
   - Inject CompanyMediaRepository, UploadFactory (or direct MinioStorage)
   - `uploadAndRecord(companyId, organizationId, file, dto)`:
     a. Run sharp(buffer).metadata() to get width, height, format
     b. Generate thumbnail: sharp(buffer).resize(300, 300, { fit: 'inside', withoutEnlargement: true }).jpeg({ quality: 80 }).toBuffer()
     c. Generate mediaId (uuid)
     d. Upload original to MinIO: key = `{companyId}/{mediaId}/{originalname}`
     e. Upload thumbnail to MinIO: key = `{companyId}/{mediaId}/thumb_{originalname}.jpg`
     f. Create DB record via repository with all metadata
     g. Return MediaUploadResult
   - `listMedia(companyId, query)`: delegate to repository
   - `getMedia(id)`: delegate to repository.findById
   - `deleteMedia(id)`: delegate to repository.deleteMedia
   - `queueVariantGeneration(mediaId, platforms)`: create MediaProcessingJob via repository (async processing handled by Plan 03)

   - `company-media.service.spec.ts`: Mock repository + sharp + MinIO upload. Test metadata extraction, thumbnail generation (verify sharp called with 300x300 inside fit), upload paths follow convention, DB record created with correct data
