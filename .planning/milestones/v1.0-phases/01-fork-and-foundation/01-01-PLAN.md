<task type="auto">
  <name>Task 1: Fork Postiz and create Docker dev environment</name>
  <files>
    docker/docker-compose.dev.yaml,
    docker/.env.dev.example,
    .env.example
  </files>
  <action>
    1. Fork Postiz v2.20.1 into the current project directory:
       - Clone from `https://github.com/gitroomhq/postiz-app.git`
       - Pin to latest stable tag (v2.20.1 or nearest available)
       - Set up git remotes: `origin` = our fork, `upstream` = gitroomhq/postiz-app
       - Create an `upstream` branch pointing at the pinned tag for future diff comparison

    2. Create `docker/docker-compose.dev.yaml` — a lightweight dev compose that does NOT include Temporal (saves ~4GB RAM):
       - PostgreSQL 17-alpine: port 5432, health check with `pg_isready`, restart unless-stopped, named volume
       - Redis 7.2-alpine: port 6379, health check with `redis-cli ping`, restart unless-stopped, named volume
       - MinIO latest: ports 9000 (S3 API) + 9001 (console), health check with curl, restart unless-stopped, named volume
       - Use env vars for credentials (not hardcoded): reference `docker/.env.dev.example`

    3. Create `docker/.env.dev.example` with all Docker service credentials:
       - POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB
       - MINIO_ROOT_USER, MINIO_ROOT_PASSWORD
       - DATABASE_URL (constructed from PG vars, pointing to localhost:5432)

    4. Create/update root `.env.example` extending Postiz's existing env example with custom vars:
       - STORAGE_PROVIDER=local (ready for s3 in Phase 4)
       - S3_ENDPOINT, S3_BUCKET, S3_ACCESS_KEY, S3_SECRET_KEY (MinIO values for local dev)

    5. Add convenience scripts to root `package.json`:
       - `"dev:docker": "docker compose -f docker/docker-compose.dev.yaml up -d"`
       - `"dev:docker:down": "docker compose -f docker/docker-compose.dev.yaml down"`
       - `"prisma:migrate": "prisma migrate dev --schema=libraries/nestjs-libraries/src/database/prisma/schema.prisma"`
       - `"prisma:generate": "prisma generate --schema=libraries/nestjs-libraries/src/database/prisma/schema.prisma"`
       - `"prisma:seed": "tsx extensions/seed/seed.ts"`

    IMPORTANT: The Prisma schema lives at `libraries/nestjs-libraries/src/database/prisma/schema.prisma` (NOT project root). All prisma CLI commands must use `--schema` to point there. See Research Pitfall #2.

    IMPORTANT: Do NOT modify any existing Postiz migration files. Only add NEW migration files.
  </action>
  <verify>
    <automated>docker compose -f docker/docker-compose.dev.yaml config --quiet && echo "Compose config valid"</automated>
  </verify>
  <done>
    - Postiz v2.20.1 cloned with `upstream` remote and `upstream` branch configured
    - Docker Compose dev file validates and defines PostgreSQL, Redis, MinIO with health checks and restart policies
    - `.env.dev.example` documents all required environment variables
    - Root `package.json` has prisma and docker convenience scripts
  </done>
